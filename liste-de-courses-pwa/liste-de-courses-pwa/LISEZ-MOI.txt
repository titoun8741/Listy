Liste de courses - application web installable (PWA) avec comptes

Contenu : index.html, manifest.webmanifest, sw.js, supabase.sql, dossier icons/.

1) Base de données (une seule fois)
   Supabase > SQL Editor > New query > collez tout le contenu de supabase.sql > Run.
   Ce script peut être relancé sans risque, même si vous aviez déjà exécuté l'ancienne version.

2) Réglage des comptes (une seule fois)
   Supabase > Authentication > (Sign In / Providers) > Email :
   l'e-mail doit être activé et "Confirm email" DÉSACTIVÉ.
   Sans cela, chaque nouveau compte devra cliquer sur un lien reçu par e-mail.

3) Mettre le site en ligne (HTTPS)
   GitHub Pages : remplacez index.html et sw.js dans votre dépôt (Add file > Upload files).
   Netlify Drop, Vercel ou Cloudflare Pages fonctionnent aussi.

4) Installer sur le téléphone
   Android (Chrome) : menu > "Installer l'application".
   iPhone (Safari) : Partager > "Sur l'écran d'accueil".

Utilisation
   - Chaque personne crée son compte (e-mail, mot de passe d'au moins 8 caractères, prénom).
   - Une liste n'est visible que par ses membres.
   - Pour inviter quelqu'un : panneau Partager > donnez-lui le code de la liste ;
     il le saisit dans "Rejoindre une liste".
   - Appui long sur le nom d'une liste : la retire de VOTRE compte seulement.
     Les autres membres la gardent, et on peut la rejoindre de nouveau avec son code.
   - Les listes utilisées sur l'appareil avant l'arrivée des comptes sont rattachées
     automatiquement au premier compte qui se connecte, si elles existent encore sur Supabase.

Mise à jour : modifiez index.html puis changez VERSION dans sw.js (ex. "courses-v7").

Sécurité
   - La clé sb_publishable est faite pour être publique.
   - Les tables sont fermées : seules les fonctions de supabase.sql sont utilisables,
     et elles exigent d'être connecté ET membre de la liste.
   - Qui connaît le code d'une liste ET possède un compte peut la rejoindre : ne le partagez pas largement.
   - La création de compte est ouverte à toute personne qui connaît l'adresse du site.
   - Mot de passe oublié : pas de fonction dans l'application. Dans Supabase, Authentication > Users,
     on peut réinitialiser le mot de passe d'un utilisateur.
