Liste de courses - application web installable (PWA)

Contenu : index.html, manifest.webmanifest, sw.js, dossier icons/.

Mettre en ligne (gratuit) :
  1. Netlify : glissez ce dossier sur https://app.netlify.com/drop
     ou Vercel / GitHub Pages / Cloudflare Pages. Le site doit etre en HTTPS.
  2. Ouvrez l'adresse obtenue sur le telephone.
  3. Android (Chrome) : menu > "Installer l'application".
     iPhone (Safari) : bouton Partager > "Sur l'ecran d'accueil".

Mise a jour : modifiez index.html puis changez VERSION dans sw.js
(par exemple "courses-v2") avant de remettre le dossier en ligne.

Important : hors de Claude, le partage en direct entre personnes n'est pas actif.
La liste, les rayons, les quantites, les habituels et les listes multiples
fonctionnent, mais les donnees restent sur chaque appareil.
Pour partager en direct, il faut brancher une base de donnees (Firebase, Supabase...).
